## so101_doll_pilot — "Put the doll in the white box."（2026-10-22）

100 段，44580 帧，每段 11.0–21.3 s，10-22 11:15–12:09 白天录，四次各 25 段。检查结果：100 段末帧玩偶都在白盒内；没有不动的段（运动比例最低 45%）；时间戳、视频帧数全部对齐；顶视运动中重复帧平均 7.9%；8 段有重抓（第 1、14、27、41、46、50、52、77 段），最终都放进了盒子。未删除任何段。

| 段 | 场景 |
|---|---|
| 0–24 | 玩偶 + 一个白盒（第 0 段桌上另有装钥匙的盒子） |
| 25–49 | 玩偶 + 一个白盒 + 笔筒（干扰物），没有钥匙 |
| 50–74 | 玩偶 + 空白盒 + 装着钥匙的另一个白盒 |
| 75–99 | 玩偶 + 两个空白盒 + 桌上散放的钥匙；玩偶放进其中一个，另一个留空 |

- 第 75–99 段有两个空白盒，任务文本只说 "the white box"；用户确认放进任一个都算成功。
- 每段末尾停在起始姿态的静止尾段平均 2.9 s（2.0–4.6 s），占 19% 的帧。
- 起始姿态比钥匙数据一致：腕部旋转起始角标准差 6.7°（钥匙数据 32.6°）。
- 光照（用户）：玩偶数据的光照与晚上测试时接近；之前白天录的钥匙数据有点过曝。
